# ADR 062 — 사내 호스트의 서브에이전트 발행 차단 해제

- **날짜**: 2026-11-24
- **상태**: 활성
- **관련**: [ADR 042](042-corporate-profile-dispatch-block.md)·[ADR 038](038-corporate-profile-verification-exemption.md)·[ADR 046](046-corporate-profile-dispatch-block-restored.md)(**이 ADR이 대체**), [ADR 055](055-retire-corporate-pi-workers.md)(호스트 직접 수행 부분을 대체 — 내부 Pi 위임 폐기는 유지), [ADR 053](053-pi-profile-exception.md)(사내 발행 예외 부분이 무의미해짐 — Pi 실행·worktree 선택권은 유지), [ADR 045](045-corporate-profile-dispatch-restored.md)(같은 해제의 이전 시도), ADR 012(설치처 프로필), 스펙 `2026-08-04-dispatch-gate-hook`(폐기)

## 변경 내용

1. **설치처 프로필은 더 이상 서브에이전트 발행의 판정 입력이 아니다.** `사내` Claude/Codex 호스트도 개인과 같은 `orchestrate` 판정표, 역할 등급, `explorer`·`implementer`·`reviewer`·`troubleshooter`·`architect`·`integrator` 발행, 관점 팬아웃, 독립 리뷰를 쓴다. `infra-specialist`만 통과시키던 예외는 뜻을 잃어 함께 사라진다.
2. **`dispatch-gate.py`와 테스트를 삭제하고** Claude(`.claude/settings.json`)·Codex(`.codex/config.toml`) 등록과 무결성 R18·R21의 필수 목록에서 뺐다. 통과만 하는 훅은 폐기 코드다(전역 정책).
3. **`_common.read_profile`도 삭제했다.** 일일 점검 알림이 ADR 056으로 사라진 뒤 이 판독기를 쓰는 코드는 `dispatch-gate` 하나였다. 판독기 테스트가 붙잡던 공유 절 파서의 경계(절 한정·제목 레벨·굵은 라벨 위치·판독 실패)는 경량 모델 판독기 기준 테스트로 옮겼다. `harness-install`의 프로필 형식 고정은 유지하되, `read_profile` 실행 확인 문구는 뺐다.
4. **검증 면제가 사라진다.** `orchestrate`의 「설치처 면제」 문단, `team-review`의 사내 게이트, `project-status`의 순차 수집 안내, `metaskill` 비례성 규칙의 사내 면제, `tool-eval`·`branch-workflow`·`implementer`·`infra-specialist`·`patterns.md`의 사내 분기와 해당 한글 뷰를 무조건형으로 바꿨다.
5. **`독립 검증` 줄과 운영 로그 3상태는 유지한다.** 이 장치들이 붙잡는 것은 "검증이 실제로 돌았는가"이고 프로필과 무관한 질문이다. 문구에서 사내 분기만 빼, 검증을 못 돌렸으면 사유와 대체 근거를 적도록 일반화했다(ADR 045 5항과 같은 처리).

## 유지되는 사내 제약

- **추적 루트 하네스 파일의 수정·커밋·푸시 금지와 대기 큐**(§5·ADR 012) — 편집 권한 축이지 발행 축이 아니다.
- **반출 제한**(§3 `<private>`·데이터 유출) — 발행과 무관하다.
- **사내 내부 모델·Pi 작업자 위임 폐기**(ADR 055) — 이 ADR은 그 경로를 되살리지 않는다.

## 사유

**사용자 요청**(2026-11-24): "사내 호스트에서 서브 에이전트 발행 막아둔거 해제해." ADR 042·046이 딛고 선 판정은 "사내에서는 발행 비용을 감당할 수 없다"였고, 046은 다음에 같은 질문이 오면 다툴 것은 규칙이 아니라 **그 시점의 비용 감당 여부** 하나라고 적어 두었다. 이번 요청은 그 축의 값을 바꾼 것이다.

**042가 스스로 적은 성격**: 위반을 막는 게이트가 아니라 비용 판정의 성문화이며, 사내 설치처의 발행 실패 기록은 이 저장소에 0건이다. 지금 제거되는 것은 관측된 사고를 막던 장치가 아니다.

## 검증

- 훅 스위트 14파일 실행. `token-efficiency-contract_test.py`의 기존 실패 2건(`orchestrate`에 없는 문구 요구 — HEAD `bfb202c`에서도 해당 문구 0건)을 뺀 전량 OK. 수치와 독립 검증 결과는 변경 이력 행에 적는다.
- `integrity-check.py`의 R15·R16·R18·R21 통과.

## 영향

- **얻는 것**: 사내 세션이 개인과 같은 수집·검증 구조를 쓴다. 리뷰가 저자 밖에서 이뤄지고, 수집·리뷰 상세가 메인 컨텍스트를 채우지 않는다.
- **잃는 것**: 사내 발행 비용이 0에서 개인 수준으로 돌아온다. 이것이 이 결정이 지불하는 값이다.
- **되돌리기**: 이 ADR을 대체하는 ADR + 이 커밋의 revert. ADR 046 표대로 revert 한 번에 코드·규칙 층이 돌아오고, ADR 상태 정리만 손으로 한다.
- **관측되지 않은 채 나간다**: 이 설치처는 `개인`이라 사내 경로에서 발행이 실제로 도는지 확인하지 못했다. 사내 기계는 이 커밋을 pull해야 반영된다.
