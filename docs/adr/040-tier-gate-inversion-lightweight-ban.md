# ADR 040 — tier-gate 판정 반전: 미지정 차단에서 경량 금지 강제로

- **날짜**: 2026-08-04
- **상태**: 활성
- **관련**: [ADR 037](037-tier-gate-dispatch-enforcement.md)(이 ADR이 판정 방향을 대체), AGENTS.md 9절(티어→모델 매핑·경량 금지), ADR 005(탈모델명), ADR 012(설치처 프로필 — REGISTRY.md가 설치처 판정 입력이라는 선례), ADR 038(같은 발행 지점의 두 번째 게이트), 스펙 `2026-08-03-tier-gate-hook`

## 변경 내용

1. `tier-gate`의 판정 대상을 **`model`을 지정했는가**에서 **무엇을 지정했는가**로 바꾼다. `model` 미지정은 통과하고, REGISTRY.md 「경량 모델」 절이 나열한 등급을 지정한 발행만 차단한다.
2. `inherit`도 통과한다. **전용 분기는 두지 않는다** — 경량 목록에 없는 문자열이라 일반 경로로 통과하며, 초판의 차단 분기는 제거했다(남기면 죽은 분기다).
3. 판정 입력으로 REGISTRY.md에 **「경량 모델」 절**을 신설한다. 모델명은 이 미추적 절에만 있고 훅 코드에는 없다. 절이 없으면 훅은 발화하지 않는다(fail-open).
4. 우회는 발행 프롬프트의 `[light-ok]` — 9절 경량 예외(사용자가 명시적으로 "빠르게/가볍게"를 요청)를 옮긴 것이다. **`design` 티어에는 닿지 않는다**: 전역 정책은 조항이 둘이고, 그 예외와 **별도로** 검증·리뷰·최종 확인의 경량 사용을 절대 금지한다. 그래서 우회 판정은 티어를 읽은 뒤에 한다.
5. REGISTRY 절 판독기를 `_common.py`에 둔다(`read_lightweight_models`). 기존 `read_profile`과 절 파서를 공유한다.
6. `harness-install`이 설치 인터뷰에서 이 절을 채운다.
7. `integrity-check`에 **R20**을 신설해 그 절의 상태를 주간 점검 출력에 드러낸다(항목 있음 PASS / 없음 SKIP). 판정 입력이 gitignore 대상이라 사라져도 `git status`에 흔적이 없기 때문이다.

## 사유

**게이트가 유일한 안전 기본값을 막고, 위험한 선택은 전부 통과시키고 있었다.**

세 가지가 겹친다.

**① 사용자 전역 정책의 기본값과 정면으로 충돌했다.** 전역 정책은 "Agent 호출 시 `model` 파라미터를 **명시하지 않는다**(부모 모델 상속 — 보통 Opus/Sonnet)"를 기본값으로 정한다. ADR 037의 훅은 정확히 그 기본값을 차단했다.

**② 위험의 방향이 반대였다.** 세션 모델은 상위·표준 둘 중 하나이므로 **상속은 경량 등급에 닿을 수 없다** — 전역 정책이 절대 금지한 상태가 상속 경로에서는 구조적으로 발생하지 않았다. 명시 지정을 강제하는 순간 그 경로가 처음으로 열렸고, ADR 037은 값을 판정하지 않기로 결정했으므로 경량을 골라도 통과했다. 즉 **"금지축은 항상 준수, 가끔 낭비"를 "금지축을 위반할 수 있음"으로 바꿨다.**

**③ 그 위반이 즉시 실현됐다.** ADR 037이 신설된 2026-08-03, 수집 목적 발행이 훅에 차단됐고, 훅 메시지의 지시("9절 표에서 기준을 읽고 골라 `model`을 지정한 뒤 다시 발행하세요")를 따라 재발행된 것이 **경량 모델 발행**이었다. 사용자가 잡아냈다. 게이트가 막은 것이 아니라 **게이트가 유도한** 위반이다. 훅 자신은 값을 보지 않으므로 통과시켰다.

**게다가 앞 방향은 자기 근거를 막지 못한다.** ADR 037이 두 구간 중 **더 무겁다**고 지목한 것은 "검증 25건이 표준 모델"이었는데, 그것은 design 티어에 표준 모델을 **지정한** 상태다. 지정 여부만 보는 게이트는 그 25건을 그대로 통과시킨다. 앞 방향이 실제로 고친 것은 07-25 이후 구간의 explore 과소모, 즉 **비용 문제 하나뿐**이었다.

**그래서 축을 나눴다.** 과소모(비용)는 재작업을 부르지 않으므로 문서 규칙에 돌려주고, 경량 검증(정확성)은 false negative가 완료된 작업을 재작업시키므로 실행 계층에 남긴다. 게이트가 지키는 것은 **잘못 골랐을 때 가장 비싼 하나**여야 한다.

**ADR 005는 값 판정을 금지하지 않는다.** 금지하는 것은 모델명을 하네스에 **박는 것**이고, 그 이유는 CLI 라인업이 바뀌면 낡기 때문이다. 이름을 설치처 데이터(REGISTRY.md, 미추적)에 두면 코드는 이름을 모른 채 판정한다 — 프로필 판독(ADR 012)이 이미 쓰는 구조다. ADR 037의 「판정 기준」은 이 선택지를 검토하지 않았다.

## 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 판정 대상 | 지정된 **값**이 경량인가 | 상속은 금지 등급에 닿지 않는다. 지정만 강요하면 그 경로만 열린다 |
| `model` 미지정 | **통과**(안전 기본값) | 전역 정책의 기본값이고, 상속 경로에는 금지 위반이 없다 |
| `inherit` | 통과, 전용 분기 없음 | 경량 목록에 없어 일반 경로로 통과한다. 초판은 차단 대상이라 분기가 필요했지만 지금은 죽은 분기가 된다 |
| 모델명 위치 | REGISTRY.md 「경량 모델」 절(미추적) | ADR 005는 이름을 **코드에** 박는 것을 금지한다. 데이터에 두면 판정하면서 탈모델명이 유지된다 |
| 매칭 방식 | 소문자 + 영숫자 낱말 경계 | 별칭과 전체 모델 ID를 한 항목이 잡으면서 낱말 내부의 우연한 일치는 배제한다. 맨 부분 문자열은 다른 벤더 등급명을 오차단했다(실측: 항목 `mini`가 `gemini-2.5-pro`를 막음) |
| 우회 | 프롬프트 `[light-ok]`, **단 design 티어 제외** | 9절 경량 예외를 옮겼다(`[no-test]`·`[secret-ok]`·`[review-ok]`와 같은 계열). design을 뺀 것은 전역 정책의 절대 금지가 예외와 별개 조항이고, `reviewer`·`integrator` 정의도 예외 없이 "never"라고 적기 때문이다 |
| 강제 위치 | 발행 지점(ADR 037 유지) | 그 실측은 유효하다 — 문서 규칙은 상속을 못 이겼고, 타입 축의 성공 선례가 같은 자리에 있다 |
| 실패 방향 | fail-open(절 부재·로스터 밖·판독 실패·예외) | 비용·품질 규칙이지 3절 가드레일이 아니다(ADR 037 유지) |

## 한계

- **티어 적합성은 보지 않는다 — 이제 결함이 아니라 범위다.** design 티어를 표준 모델로 발행해도 막히지 않으며, 그것은 9절을 읽는 세션의 몫이다. 이 훅이 막는 것은 전역 정책이 **절대 금지**로 못박은 한 등급뿐이다.
- **explore 과소모가 되살아난다.** 미지정이 통과하므로 상위 모델 세션에서 수집 발행이 상위 모델을 상속하는 상태(ADR 037이 실측한 07-25 이후 구간)를 훅이 더는 막지 않는다. 수용한 비용이며, 9절 표와 orchestrate가 규칙으로 관장한다.
- **판정 입력이 미추적이라 새 설치처에서는 잠들어 있다.** 「경량 모델」 절을 채우기 전까지 훅은 발화하지 않는다. `harness-install`이 인터뷰에서 채우고, 채우지 않기로 하면 그 결과를 사용자에게 말하도록 했다. 절이 **나중에 지워지거나 비는** 경우는 `git status`에 흔적이 없으므로 `integrity-check` R20이 그 상태를 주간 점검 출력에 드러낸다(PASS/SKIP — 안 채운 설치처가 무결성 실패로 시작하지 않도록 FAIL로 만들지 않았다).
- **미지정이 안전하다는 전제는 로스터 안에서만 참이다.** 서브에이전트 타입 정의가 자체 모델을 가질 수 있고, 실제로 이 설치처의 로스터 밖 타입 하나가 `model` 미지정 발행에서 경량 모델로 돌았다(2026-08-02 로그). 하네스 로스터 에이전트는 자기 모델을 박지 않음을 확인했으므로 게이트 관장 범위 안에서는 전제가 유지되지만, **강제되는 것이 아니라 관찰된 사실**이다 — 로스터 정의에 `model:`을 넣으면 깨진다.
- **로스터 밖 타입은 통과한다.** `general-purpose` 등으로 경량 발행을 하면 걸리지 않는다(ADR 037·038과 같은 구멍).
- **우회 표식의 주체가 게이트 대상이다.** `[light-ok]`를 붙이는 것은 세션 자신이므로 기계적 보증이 아니다 — 값은 우회가 기록으로 남는다는 점이다.
