# ADR 037 — 티어 매핑의 실행 계층 승격 (tier-gate 발행 게이트)

- **날짜**: 2026-08-03
- **상태**: 활성
- **관련**: AGENTS.md 9절·10절, ADR 005(탈모델명), ADR 023·028(게이트의 실행 계층 승격 선례), ADR 029·031(Codex 훅 파리티), 스펙 `2026-08-03-tier-gate-hook`

## 변경 내용

1. 서브에이전트 발행 시 `tier`가 선언된 에이전트에 `model` 파라미터가 없으면 **차단**하는 PreToolUse 훅(`.agents/hooks/tier-gate.py`)을 신설한다.
2. 훅은 **어느 모델을 골랐는지 판정하지 않는다** — 지정 여부만 본다. 단 `inherit`는 상속 지시어이므로 미지정과 동치로 처리한다.
3. 티어는 `.agents/agents/<name>.md` frontmatter에서 읽는다(10절이 정의 파일을 티어 선언의 원본으로 규정).
4. 9절의 추론 등급 컬럼은 **표현 가능한 경로의 선택 규칙**으로 한정한다 — Claude Code Agent 도구에는 발행 파라미터가 없다.

## 대상

`.agents/hooks/tier-gate.py`(신설), `.agents/hooks/tier-gate_test.py`(신설), `.claude/settings.json`, `.codex/config.toml`, `AGENTS.md` 9절, `AGENTS.ko.md`, `.agents/skills/orchestrate/SKILL.md`, `.agents/skills/metaskill/references/agent-rules.md`, `.agents/hooks/harness-review-reminder.py`, `README.md`, `docs/README.md`, `docs/specs/2026-08-03-tier-gate-hook.md`

## 사유

9절 표는 초기 하네스부터 존재했지만 **적용된 적이 없었다.** 적용 수단이 발행 시점의 `model` 파라미터 하나인데, 지정하지 않으면 서브에이전트가 부모 세션 모델을 그대로 상속하기 때문이다. 그래서 표가 아니라 **그때 세션 모델이 무엇이었느냐**가 결과를 정했고, 어느 티어가 위반 상태인지만 뒤바뀌었다(2026-08-03 실측, 이 설치처 로컬 세션 로그):

- ~07-22: explore는 대체로 준수(표준 11 / 상위 4), 그러나 **design 티어 25건이 표준 모델**(표준 25 / 상위 11)
- 07-25~: 세션이 상위 모델에 앉으면서 explore가 상위 21 / 표준 3으로 역전

앞 구간이 더 무겁다. 검증을 저성능 모델로 돌리는 것은 사용자 전역 정책이 **절대 금지**한 상태이며(false negative가 완료된 작업을 재작업시킨다), 9절이 경량 모델 금지를 따로 못박은 이유다.

**문서 규칙을 더 적는 것으로는 고쳐지지 않는다는 근거가 같은 데이터에 있다.** 9절은 처음부터 이 표를 갖고 있었고 그럼에도 상속이 늘 이겼다. 반대 사례도 있다 — 에이전트 **타입**은 2026-07-17에 리마인더 훅 문구로 처방한 뒤 유지됐다. 즉 이 하네스에서 실효가 확인된 처방 위치는 **발행 지점**이다. 사용자 지적("안 지켜지면 왜 넣느냐")이 이 판단의 출발점이다.

## 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 강제 위치 | 발행 시점 PreToolUse 차단 | 문서 규칙은 상속을 못 이긴다(위 실측). 타입 축의 성공 선례가 같은 위치 |
| 판정 기준 | `model` 지정 여부만 | 모델명을 코드에 박으면 ADR 005가 깨지고 CLI 라인업 변경마다 훅이 낡는다 |
| `inherit` | 미지정과 동치로 차단 | 모델명이 아니라 상속 지시어다 — 통과시키면 막으려는 상태가 한 단어로 되살아난다 |
| 티어 출처 | 에이전트 정의 frontmatter | 10절이 정의 파일을 원본으로 규정. 로스터가 늘어도 훅 수정 불요 |
| 실패 방향 | fail-open(로스터 밖·판독 실패·예외·훅 파일 부재) | 비용·품질 규칙이지 3절 가드레일이 아니다. 등록 shim도 파일 부재 시 exit 0 |
| 추론 등급 | 게이트 대상 아님 | Claude Code Agent 도구에 파라미터가 없다(실측) |

## 한계

- **우회 가능하다.** 판정 입력인 에이전트 정의를 기준 디렉토리에서 찾으므로 기준이 어긋나면 통과한다. 3절 가드레일이 아니므로 수용한다.
- **티어 적합성은 보지 않는다.** 지정만 하면 통과하므로 잘못된 티어의 모델을 골라도 막히지 않는다. 게이트가 끊는 것은 상속이지 오선택이 아니다.
- **Codex 발행 도구 이름 미실측** — 매처 후보 3종을 걸었고, 어긋나면 발화하지 않을 뿐이다(ADR 031: Codex 런타임 판정은 이 하네스 세션의 몫이 아니다).
- **실효 미관측** — 등록 이후 세션에서만 확인된다. 다음 주간 점검에서 같은 집계를 다시 내어 미지정 비율을 비교한다.
