# ADR 061 — 지식 노트는 명시적 요청에만 읽기

- 날짜: 2026-10-16
- 변경: 설계 단계 자동 조회를 폐기하고 사용자 요청을 읽기 조건으로 삼는다.
- 대상: `AGENTS.md`, `AGENTS.ko.md`, `CLAUDE.md`, `.agents/skills/metaskill/SKILL.md`, `.agents/skills/tool-eval/SKILL.md`, `.agents/skills/harness-install/SKILL.md`, `REGISTRY.md`, `docs/adr/033-knowledge-source-routing.md`, `docs/adr/061-knowledge-notes-explicit-request.md`, `docs/README.md`, `docs/harness-changelog.md`
- 사유: 사용자는 초반 작업에서 명시적으로 요청하지 않은 지식 노트 읽기를 제거해 달라고 했다. 직전 검토 작업에서도 자동 조회가 시도됐고 연결 노트 읽기가 시간 초과됐다.

## 결정

REGISTRY.md의 연결 상태는 경로 정보다. 새 프로젝트, 기능 스펙, 도구 채택, 하네스 변경은 그 자체로 노트 읽기를 허가하지 않는다. 사용자가 지식 노트 활용을 명시적으로 요청했을 때만 기록된 진입점을 읽는다. 설치 시 연결 확인은 파일 메타데이터로만 하고 내용을 열지 않는다. 실제 가독성은 요청받은 읽기 또는 쓰기 시점에 확인한다.

노트를 읽은 경우에도 기존의 근거 등급, 외부 반출, 비신뢰 자료 표시, 읽기 실패 처리 규칙은 유지한다. `vault-write`를 통한 명시적 작성 요청은 이 읽기 조건과 별개다. 최신성이나 외부 사실이 필요하면 해당 1차 출처를 직접 확인한다.

## 검증 기준

- 일반 설계·도구 검토·하네스 변경 지침에 자동 노트 조회 지시가 남지 않는다.
- 설치 절차는 노트 바이트를 읽지 않는다.
- 명시적 읽기 요청에는 경로·근거·반출 계약이 적용된다.
- 노트 작성 요청에는 `vault-write` 계약이 유지된다.
