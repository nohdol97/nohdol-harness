# ADR 059: Paperclip 협업과 CLI orchestration 분리

- 날짜: 2026-10-15
- 상태: 활성
- ADR 057의 Paperclip 실행 계약을 구체화한다. ADR 055의 일반 사내 CLI 직접 수행 정책은 유지한다.

## 배경
원본 역할·스킬을 연결하면서 orchestrate까지 관리자에게 배정했고, 사내 CLI의 직접 수행·에이전트 호출 금지·독립 검토 면제 문구도 전달됐다. 사용자가 Paperclip이 역할을 배정하는 환경에 이러한 절차와 금지를 그대로 적용하는 것이 맞지 않다고 지적했다.

## 결정
Paperclip의 배정·실행·재시도와 관리자의 판단을 분리한다. 관리자에게 작업 분해·완료 기준·역할 선택·독립 검토·통합 책임을 명시하되, CLI의 팀 규모 gate와 native worker 생성 절차는 요구하지 않는다. orchestrate/autoloop는 실행 스킬 배정에서 제외하며 이 설치의 기존 배정만 remove한다. 원본과 라이브러리 참조 사본은 보존한다.

루트 §11에 실제 Paperclip 실행 문맥에서만 적용되는 예외를 둔다. 전용 runtime 계약이 원본의 CLI orchestration과 사내 direct-execution/dispatch-ban/self-review-exemption 조항을 대체한다. 환경 변수나 문서 언급만으로 활성화하지 않으며, 주입된 신원을 Paperclip API에서 확인해야 한다. 일반 CLI/Pi 정책과 native dispatch hook은 수정하지 않는다.

가져오는 SKILL.md에는 YAML 뒤에 Paperclip 전용 안내를 붙이고 원문·참조 파일·원본 hash를 보존한다. 역할 지침과 관리자 블록도 동일 계약을 참조한다. 복사본의 원문을 광범위한 키워드 삭제로 훼손하거나 사내 정책 전체를 제거하지 않는다.

독립 검토·SDD/TDD·역할 경계·worktree·누락 하네스 정지는 유지한다. 데이터 반출·사내 루트 수정 제한·비밀·도구/sandbox 권한·파괴 작업 승인은 협업 예외와 별개다. 배정 경로의 허용을 모델 호출이나 paused 에이전트 재개 권한으로 해석하지 않는다.

## 대안과 한계
- orchestrate 원본 전체를 실행: 두 스케줄러와 사내 제한이 혼재해 제외.
- 사내 관련 문구 전부 삭제: 반출·승인 등 보존할 규칙까지 지워질 수 있어 제외.
- Paperclip이 알아서 검토를 보장한다고 간주: 검토 정책은 이슈별 설정이므로 제외.

계약은 모델 지침이며 서버 권한 강제 장치가 아니다. 실제 모델을 호출하는 제품 E2E는 외부 작업 통신 범위가 확정되기 전에는 실행하지 않는다. 이 변경의 검증은 offline 회귀·독립 검토와 로컬 API 지침/배정 확인이다.

## 변경 이력
### 자율 개발 판단 보완 (2026-10-15)
Paperclip 실행에서 가역적인 개발 세부 사항과 작업 범위 안의 스펙 확정은 coordinator가 맡는다. 이전 역할·스킬 사본의 인터뷰 기본값이나 사용자 스펙 확정 문구는 전용 runtime 계약으로 대체한다. 독립 에이전트 검토와 사용자 승인을 구분하고, 필수 정보 부재·중대한 범위 변경·권한/반출/파괴적 조치의 인간 결정은 유지한다. 기존 pending 항목을 임의 처리하지 않으며 설치 자체가 실행을 깨우지 않는다. 범위와 근거는 [자율 판단 스펙](../specs/2026-10-15-paperclip-autonomous-decisions.md)에 기록한다.
