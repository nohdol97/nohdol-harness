# ADR 060: Paseo에서 로컬 Paperclip 패널 제공

- 날짜: 2026-10-15
- 상태: 활성

## 배경
폰에서 Paperclip을 조작하기 위해 사용자가 Paseo 패널 방식을 선택했다. 채팅 경유 방식은 조회 결과를 모델에 보내며, 두 앱이 개발 작업을 배정하면 중복 실행이 발생할 수 있다.

## 결정
기존 `.agents/integrations/paperclip/` 아래에 Paseo 플러그인을 둔다. 사이드바 화면과 워크스페이스 패널에서 같은 React Native UI를 사용한다. 폰은 Paseo의 인증된 연결로 RPC를 호출하고, 데몬 측 플러그인은 같은 컴퓨터의 Paperclip loopback API에 연결한다. 모델이나 새 스케줄러는 사용하지 않는다.

Paperclip의 설정·환경 변수·원시 실행 로그를 넘기는 범용 프록시 대신, 조회와 제한된 조작별 RPC를 정의한다. 반환 필드를 선별하고 회사 소속을 확인한다. 네트워크 목적지는 고정된 로컬 주소이며 프록시·리디렉션은 사용하지 않는다.

첫 버전에서 쓰기는 미배정 backlog 초안과 확인 후 에이전트 일시정지만 제공한다. 댓글·상태 변경도 실행을 깨울 수 있으므로 모델 호출 재개 결정과 분리한다. 초안 제목은 필수이며 자동 제목 생성·watchdog·외부 object 검출 경로를 차단한다. 일시정지는 현재 실행 취소를 포함함을 화면에 알린다.

## 대안과 한계
### 작업·응답 확장 (0.2)
사용자는 같은 패널에서 작업 요청, 질문 답변, 확인·승인, 차단 후속 조치까지 처리하는 확장을 승인했다. 신규 작업은 담당자에게 `todo`로 배정하며 Paperclip 자체 실행 예약을 사용한다. 중복 wake를 추가하지 않는다. 일시정지된 담당자는 자동으로 깨우지 않고, 다른 대기 작업도 실행될 수 있음을 알린 별도 재개 확인을 제공한다.

응답함은 Paperclip attention API를 페이지 단위로 조회한다. 질문·확인은 전용 API로 전달하고 제출 전 회사 소속·현재 상태·판단 내용의 fingerprint를 재확인한다. 이는 upstream의 원자적 CAS를 대신하지 않는다. 비밀 연결·도구 실행·채용·예산 등 지원하지 않는 요청은 사유와 함께 표시한다. 차단은 의존 작업, 질문·승인 대기, 예약 재시도와 정확한 실패 실행으로 구분하며 일괄 `in_progress` 전환을 제공하지 않는다.

쓰기에는 사용자 확인과 operation ID를 요구한다. 생성은 Paperclip의 idempotency key를 사용하고, 나머지 조작은 로컬 실행 잠금·영수증으로 반복 전송을 막는다. 응답 유실은 성공으로 추정하거나 자동 재시도하지 않는다. 답변 저장·작업 접수와 모델 실행 시작은 별도로 표시한다. 패널을 열어 두는 동안 갱신하며 알림용 외부 서비스를 추가하지 않는다. 범위와 검증 기준은 [확장 스펙](../specs/2026-10-15-paseo-paperclip-actions.md)에 기록한다.

### 연결 방식
- 채팅 + MCP: 자연어 지시는 편리하지만 조회와 조작에도 모델 호출이 필요해 이번 범위에서 제외한다.
- 웹 화면 iframe: 폰의 localhost는 컴퓨터를 가리키지 않고, Paseo의 네이티브 모바일 화면과도 맞지 않아 제외한다.
- Paperclip 포트 공개: 패널 연결에 필요하지 않다. local_trusted·loopback을 유지한다.

Paseo 플러그인은 샌드박스가 아닌 신뢰하는 로컬 코드다. 현재 Paperclip의 로컬 사용자 신뢰 모델을 계승하므로 다중 사용자 권한 격리를 제공하지 않는다. Paseo 연결을 통해 보이는 업무 내용은 해당 폰에도 전달된다. 공식 릴레이를 선택하면 내용은 암호화되지만 접속 메타데이터는 중계 서버에 보일 수 있다. 네트워크 경로 선택은 패널 구현과 구분한다.

사용자는 기존 암호화 릴레이 유지를 선택했다. 로컬 플러그인 실행·실제 조회·390px 웹 화면·오류 복구를 검증했으며 실물 폰과 릴레이 경유 검증은 별도다. 설치·검증의 상세 근거는 [스펙](../specs/2026-10-15-paseo-paperclip-panel.md)에 기록한다.
