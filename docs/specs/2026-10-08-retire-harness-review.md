# 스펙: 일일·주간 하네스 리뷰 제거

- 날짜: 2026-10-08 / 상태: 구현됨
- 관련: ADR 056

## 배경
사용자가 harness-review의 일일·주간 모드를 모두 제거하도록 요청했다.

## 목표
스킬과 자동 시작 알림을 제거하고 현재 운영 지침을 이에 맞춘다.

## 비목표
다른 훅, 수동 무결성 검사, 관찰된 개선 신호의 metaskill 처리, 과거 이력과 로컬 점검 결과 삭제.

## 요구사항
- R1: harness-review 스킬과 전용 알림 훅을 제거한다.
- R2: Claude·Codex SessionStart 등록 및 무결성 필수 목록에서 알림을 제거한다.
- R3: 공용 프로필 판독기와 다른 훅의 회귀 검증을 유지한다.
- R4: 활성 규칙·설치·라우팅·한국어 요약에서 정기 리뷰 실행 지시를 제거하고 폐기 이력을 남긴다.

## 인터페이스 / 설계 개요
두 런타임의 SessionStart에서 리뷰 알림 등록을 삭제한다. 무결성 검사는 남아 있는 훅만 필수로 판정한다.

## 완료 기준 (테스트 가능한 형태)
- [x] C1 (R1): 스킬과 전용 훅 파일이 없고 두 런타임 등록에 리뷰 명령이 없다.
- [x] C2 (R2, R3): 무결성·공용 부트스트랩·발행 게이트 테스트가 통과하며 프로필 파서 경계 테스트가 유지된다.
- [x] C3 (R4): AGENTS·CLAUDE·활성 스킬 안내에서 일일·주간 실행 지시가 없고 README 목록과 한국어 요약이 맞는다. docs/README에는 폐기 결정 링크를 넣는다.
- [x] C4 (R3): 기존 cp949·인터프리터 실패 관련 공용 훅 테스트가 통과한다. 새 외부 CLI 판정은 없으며 실제 Windows 실행은 범위 밖이다.

## 미해결 질문
없음. 요청에 제거 대상이 명시되어 있고 독립 검증을 실행할 수 있다.
