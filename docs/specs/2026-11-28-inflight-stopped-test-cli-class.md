# 스펙: in-flight survey 정지 판정의 CLI 종류 인식

- 날짜: 2026-11-28
- 상태: 초안(미구현 — 설계 미확정)
- 대상: `.agents/skills/orchestrate/references/inflight-survey.md` 「Separate your own work first」의 정지 판정, `.agents/skills/branch-workflow/SKILL.md` 머지 7단계 정리, `carryover` 노트 템플릿, `session-handoff.py spawn` 인계 노트
- 관련: 루트 AGENTS.md §3·§14, `_workspace/harness-ops-log.md` 2026-11-27 [관측], 하네스 전수 점검(2026-11-27) D축 6항

## 배경

정지 판정("작성자가 멈췄음이 입증됨")은 재개 시 인계 worktree 제외, 선언된 작업의 해제, 대기 감시 해제, 머지 직후 남의 worktree 정리를 모두 결정한다. 그런데 그 근거인 `ListAgents`는 Claude Code 세션만 보이고, Windows의 MSYS `ps`는 네이티브 프로세스(`pi`·`node`)를 못 본다. 2026-11-27 사내 Windows 설치처에서 살아 있는 Pi 동료가 이 두 출처로 "정지"로 판정되어 머지 후 worktree가 정리됐다(작업 손실 없음 — `git worktree remove`가 `--force` 없이 성공했다).

전수 점검에서 이 공백을 정지 판정의 조건으로 메우려던 초안 두 개가 연달아 독립 검증 BLOCK을 받았다.

1. **"노트 시각 이후에 쓰인 세션 파일이 없을 것"** — 작성자는 노트를 쓴 뒤에도 자기 기록 파일을 계속 쓴다. 실측: 인계 노트 mtime 1785686267, 그 노트를 쓴 Claude 기록 파일 mtime 1785705472(약 5.3시간 뒤). 조건이 모든 작성자에게 거짓이 되어 재개가 자기 작업을 영원히 남의 것으로 본다.
2. **"작성자가 `ListAgents`가 못 보는 CLI이거나 노트가 CLI를 밝히지 않으면, 그 CLI의 최근 30분 세션 파일이 없을 것"** — 어떤 노트 템플릿도 작성자 CLI를 기록하지 않아 조건이 모든 재개에 걸리고, Pi는 `PI_SESSION_FILE` 포인터 없이는 확인 불가(미검증)라 역시 모든 작성자가 정지 미입증이 된다. Codex 재개 세션은 자기 rollout 파일을 제외할 방법도 없다. (Claude·Codex가 재개하는 경우 전부 실패하고, Pi 재개 세션만 원리상 Pi 종류를 확인할 수 있다.)

두 실패의 공통 원인은 **판정 입력(작성자의 CLI와 세션)이 기록되지 않는다**는 것이다. 조건 문구를 더 다듬는 것으로는 풀리지 않는다.

## 목표

- 작성자의 CLI 종류와(가능하면) 세션 식별자를 인계 시점에 기록한다.
- 기록된 종류에 따라, 그 종류를 볼 수 있는 출처로 정지를 판정한다. 볼 수 없는 출처만 있으면 "미검증"으로 남는다.
- 멈춘 작성자는 실제로 정지로 판정될 수 있어야 한다(판정이 원리적으로 불가능한 조건 금지).

## 비목표

- 다른 기계의 세션 판정.
- Pi 기본 세션 디렉토리의 추정 — 실측 전에는 경로를 쓰지 않는다.

## 요구사항(후보)

- R1: carryover 노트 템플릿과 §14 후속 세션 인계 노트에 `Author CLI`(claude/codex/pi)와 알 수 있으면 세션 식별자(Claude `CLAUDE_CODE_SESSION_ID`, Pi `PI_SESSION_FILE`, Codex는 확인 필요)를 기록한다.
- R2: 정지 판정은 기록된 CLI에 맞는 출처를 쓴다 — Claude: `ListAgents` gone/idle; Codex·Pi: 작성자 세션 파일(식별자가 있으면 그 파일만)이 최근 N분 안에 쓰이지 않았고, 그 CLI의 프로세스를 볼 수 있는 출처(Windows는 `Get-CimInstance Win32_Process`)에 해당 프로세스가 없을 것.
- R3: `Author CLI`가 없는 노트(과거 노트)는 현재 규칙(`ListAgents` where available)을 따르되, 그 CLI가 설치돼 있지 않은 종류(예: `pi` 바이너리·세션 디렉토리 없음)는 판정에서 제외한다.
- R4: 재개 세션은 자기 세션 파일을 제외하는 방법을 CLI별로 갖는다(Codex 방법 확인 필요).

## 완료 기준(후보)

- C1: 멈춘 Claude·Codex 작성자 각각에 대해 판정이 "정지"를 낸다(계약 시험 또는 고정 데이터 시험).
- C2: 최근 30분 안에 기록을 쓴 Codex 작성자에 대해 판정이 "정지 아님"을 낸다.
- C3: Pi 작성자에 대해 포인터가 없으면 "미검증"을 낸다.
- C4: 위 각 시험은 해당 조건을 지우는 변이에서 빨개진다.

## 미확인 사항

- Codex 세션이 자기 세션/스레드 식별자를 셸에 노출하는지.
- Pi 기본 세션 디렉토리.
- Windows에서 `Get-CimInstance` 출력으로 루트 경로를 연결하는 방법.
