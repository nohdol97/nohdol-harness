# Paperclip 레지스트리 연결·외부 수집 비활성화

## 목표
사용자가 요청한 로컬 REGISTRY.md의 프로젝트·경로·규칙·관계·이관 정보를 Paperclip에 반영하고, Paperclip의 선택적 외부 데이터 수집을 비활성화한다.

## 범위와 요구사항
- R1: REGISTRY.md를 원본으로 유지한다. 프로젝트별 이름·설명·작업 경로·중앙 규칙 경로·하네스 상태·연관 관계·이관 구분을 로컬 Paperclip 프로젝트/워크스페이스에 연결한다. 설치 데이터는 Git 추적 코드에 넣지 않는다.
- R2: 별도 registry_sync.py는 기본 dry-run, --apply에서만 쓴다. 원본 프로젝트·레지스트리·하위 규칙을 수정하지 않으며 업무·에이전트 실행·git fetch를 만들지 않는다.
- R3: 관리 표식이 없는 동명 프로젝트를 덮어쓰지 않는다. 재적용은 같은 ID를 유지하고 변경 없는 객체에는 PATCH하지 않는다. 레지스트리에서 빠진 프로젝트는 보고만 하고 삭제하지 않는다.
- R4: 실제 저장소와 하위 규칙 존재를 확인하고 미확인/누락 상태를 명시한다. 파일 누락을 확인된 부재로 바꾸지 않는다. 제품 작업 시 원본을 다시 읽고 기존 §7 정지 조건을 적용한다. 프로젝트 상태와 이관 구분은 별도다.
- R5: 제품 프로젝트는 격리 worktree 정책을 설정하며, 등록만으로 worktree나 제품 업무를 생성하지 않는다. 로컬 경로만 사용하고 원격 저장소를 탐색하지 않는다.
- R6: 설치된 코드로 사용 통계·업데이트 확인·Sentry·OpenTelemetry·피드백 공유·클라우드 연결·외부 백업 설정을 점검하고 가능한 옵션을 끈다. 설정 비활성화와 OS 수준 통신 차단을 구분해 보고한다.
- R7: 외부 AI 작업 호출 허용 여부는 사용자 답변을 따른다. 답변 전 추가 모델 호출·외부 연결 테스트·원격 Git 작업을 수행하지 않는다. 개인정보가 담길 수 있는 원본 설정·비밀 값은 로그나 저장소에 복사하지 않는다.

## 완료 기준
- [x] C1: 현재 레지스트리의 프로젝트가 로컬 Paperclip에 정확한 경로·규칙·관계·이관 정보로 등록된다.
- [x] C2: dry-run 무변경, 재적용 ID 유지·불필요 PATCH 없음, 외부 자산 충돌·누락 상태를 회귀로 확인한다.
- [x] C3: 기존 프로젝트·업무·역할과 원본 레지스트리/하위 저장소를 보존한다.
- [x] C4: 서비스 재시작 후 텔레메트리·업데이트·오류/추적 보고·피드백 공유의 유효 설정을 검증하고 외부 전송 한계를 보고한다.
- [x] C5: 관련 테스트·무결성·독립 검토가 통과하고 운영 안내를 갱신한다.

## 검증 결과
2026-10-15 로컬 설치에서 7개 항목을 등록했다. 최초 7회 POST 뒤 재적용 쓰기 0회·ID 동일을 확인했다. 원본 레지스트리와 중앙 규칙 hash, 제품 HEAD·git status·worktree 목록 및 기존 프로젝트 2개·업무 5개를 대조해 보존을 확인했다. 역할 7개의 실행 지침도 갱신했으며 계정 검사를 유발하는 agent 설정 변경은 없었다.

`registry_sync_test.py` 14개와 무결성 53개가 통과했다. 독립 검토가 발견한 비관리 기본 workspace 선택 문제는 쓰기 전 충돌 거부로 수정하고 원 재현과 실제 설치 API 스키마로 검증했다. runtime·운영 문서·스펙 독립 검토 PASS.

재시작한 서비스의 telemetry·업데이트·OTel 환경과 공유 거부 설정을 확인했다. 설치 코드의 오프라인 실행에서 telemetry fetch·state 쓰기 0회, frontend/backend Sentry DSN 없음, feedback 목적지 loopback을 확인했다. 실행 중 연결 표본은 모두 loopback이었다. 이 표본은 미래의 전체 outbound 봉쇄 증거가 아니며 설정도 OS 방화벽을 대체하지 않는다.

모델·외부 작업 통신의 허용 범위는 아직 확정되지 않아 원래 idle이던 에이전트 8개를 일시 정지한 상태로 유지했다. 모델 호출 테스트·원격 Git 작업은 수행하지 않았다. 제품 작업 E2E와 자동 worktree 격리는 미검증이며, 인스턴스의 실험적 자동 격리 옵션은 기존 off 상태를 보존했다. 실제 작성 전 전용 worktree 연결이 필요하다. 상세 설치 근거는 미추적 `_workspace/paperclip-registry-privacy/`에 보관한다.

제품 코드 변경, 분석 엔진 설치, 프로젝트 간 관계 추정, 방화벽 전체 재설정, 기존 데이터 삭제는 포함하지 않는다.
