# 스펙: 목표·범위 기반 자율 진행

- 날짜: 2026-10-15 / 상태: 구현됨
- 관련: AGENTS.md §13-0, 사용자 하네스 수정 요청

## 배경
기존 사전 인터뷰 기본값과 작업 중 질문 금지는 가역적인 선택도 사용자에게 넘기고, 뒤늦게 발견한 필수 정보 누락은 추측하게 할 수 있다. 사용자는 목표·범위를 주면 조사부터 검토까지 진행하도록 요청했다.

## 목표
에이전트가 범위 안의 세부 결정을 맡고, 사용자 판단이 필요한 경계에서만 질문한다.

## 비목표
안전 확인, 설치처 권한, 독립 검토, SDD/TDD 의무와 기존 배포 권한을 바꾸지 않는다. 실행기나 외부 서비스를 수정하지 않는다.

## 요구사항
- R1: 목표·범위가 주어지면 조사·스펙 확정·구현·테스트·검토까지 진행한다. 별도 스펙 승인 대기를 기본으로 두지 않는다.
- R2: 알아낼 수 있는 정보는 직접 조사한다. 범위 안의 가역적 세부 결정은 직접 내리고 선택·이유를 결과에 기록한다.
- R3: 목표·범위의 큰 변경, 조사해도 얻을 수 없는 필수 정보, 되돌리기 어려운 조치에만 질문한다. 작업 도중에도 같은 기준을 적용하고 해당 결정에 의존하는 작업은 답을 기다리며 독립 작업은 계속한다.
- R4: §3 안전 확인과 기존 권한·검증 의무를 유지한다. 무응답은 승인이나 정보의 대체가 아니다.
- R5: 루트 규칙, Claude 앵커, orchestrate, architect, metaskill, doc-writer 및 한국어 보기를 정렬한다.

## 인터페이스 / 설계 개요
질문 여부는 R3의 조건에 해당하는지로 결정한다. 해당하면 의존 작업을 보류하고 질문하며, 아니면 직접 판단해 진행한다. 정본은 AGENTS.md §13-0이며 각 역할·스킬은 이를 참조한다.

## 완료 기준 (테스트 가능한 형태)
- [x] C1 (R1·R2): 목표가 명확하고 CSV 파일명·구분자가 미지정인 시나리오에서 기존 관례를 조사하고 가역적 값을 정해 진행한다.
- [x] C2 (R3): 필수 외부 계약이 조사로 확보되지 않는 시나리오에서 작업 도중에도 질문하고 관련 구현을 추측하지 않는다.
- [x] C3 (R3·R4): 큰 범위 변경과 DB 삭제 시나리오에서는 질문하며 무응답으로 진행하지 않는다.
- [x] C4 (R1·R5): 활성 지침에 불확실성만으로 인터뷰를 강제하거나 스펙 확정을 매번 사용자에게 요구하는 충돌이 없고, 한국어 보기가 같은 기준을 설명한다.
- [x] C5 (R4·R5): 구조 무결성 검사와 독립 검토를 수행하고 결과·미검증 범위를 기록한다.

## 미해결 질문
없음. 목표·범위와 질문 조건은 사용자 요청에 명시되어 있다.

검증: 단일 변경 전·후 규칙 시뮬레이션과 독립 검토 PASS. Claude 앵커 회귀 테스트 통과. 무결성 검사는 이번 변경 관련 항목을 통과했고 동시 작업 중인 별도 Paperclip 스펙의 인덱스 누락이 남아 있다. 실제 새 CLI 세션의 반복 준수율은 미검증이다.
