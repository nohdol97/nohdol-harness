# 스펙: 사내 프로필 worktree 복원

- 날짜: 2026-09-08 / 상태: 구현됨
- 관련: ADR 035·043, ADR 052

## 배경
사용자가 사내 환경에서도 Git worktree를 허용하도록 요청했다. ADR 043의 사이트별 예외가 시작·재개·정리 절차와 autoloop 안내에 남아 있다.

## 목표
사내 하위 프로젝트에도 기존 worktree 절차를 적용하고, 무인 루프의 작업 위치 격리는 유지한다.

## 비목표
사내 서버의 인증·커밋·푸시·PR 성공 여부 확인, 기존 체크아웃의 자동 이동, 설치처 프로필의 다른 정책 변경.

## 요구사항
1. R1: 개인·사내 모두 하위 프로젝트 파일 변경에 `branch-workflow`의 전용 worktree 절차를 적용한다. 의존성 부트스트랩·PR·머지 확인·비강제 정리 조건은 유지한다.
2. R2: 재개·에이전트 작업 경로·마무리·한국어 뷰에서 사내 worktree 금지 전제를 제거한다. 기존 Branch 전용 이월 노트의 안전한 재개 안내는 과거 기록 호환으로 남긴다.
3. R3: autoloop은 프로필과 관계없이 공유 체크아웃을 거부하고 worktree 생성 방법을 안내하며, 연결된 worktree는 허용한다. 프로필을 읽지 않아도 같은 판정을 한다.
4. R4: ADR 043의 사내 예외만 대체하고 부트스트랩 결정과 과거 기록을 보존한다. 실제 사내 서버 동작을 검증했다고 주장하지 않는다.

## 인터페이스 / 설계 개요
프로필별 예외를 삭제해 기존 worktree 계약으로 합친다. autoloop의 R18 판정은 유지하고 거부 문구를 공통화한다. 새로운 명령 인자나 설정은 없다.

## 완료 기준 (테스트 가능한 형태)
- [x] C1 (R1·R2): 현재 규칙·절차·한국어 뷰에 사내 worktree 금지가 없고, 과거 Branch 전용 노트는 변경 사항 확인 후 해당 브랜치로 재개하도록 안내한다.
- [x] C2 (R3): 사내·개인·프로필 부재에서 공유 체크아웃을 거부하면서 `worktree add`를 안내하고 연결된 worktree를 허용한다.
- [x] C3 (R3): 기존 R18 회귀와 전체 driver 테스트가 통과한다.
- [x] C4 (R4): ADR·문서 목차·변경 이력의 대상 목록과 상태가 실제 diff와 일치하고 integrity 검사를 통과한다.

## 미해결 질문
없음. 사용자 요청이 사이트 예외 철회를 승인했다. 사내 서버 접근은 이번 작업의 전제가 아니다.
