# REA 채택 — 명시 호출 전용 `rea` 스킬

- 날짜: 2026-11-25 / 상태: **채택** (사용자 요청)
- 대상: https://github.com/morluto/rea (MIT, npm `rea-agents`)

## 대상 요약

바이너리·JavaScript/Electron 앱·.NET·패키지·기록된 트래픽을 분석하는 MCP 서버 겸 CLI. 분석은 로컬에서 하고, 깊은 네이티브 분석은 Hopper·Ghidra·IDA·Kuna 같은 별도 엔진이 필요하다.

## 판정

| 축 | 결과 |
|---|---|
| 중복 | 소스 없는 배포물의 역분석을 맡는 하네스 스킬이 없다. 소스 저장소 분석은 `explorer`가 계속 맡는다 |
| 상시 비용 | 상류 `setup`·플러그인은 MCP 서버와 자동 트리거 스킬을 등록하므로 채택하지 않는다. 얇은 스킬이 CLI를 호출할 때만 실행한다 |
| §3 유출 | README는 로컬 분석이라고 밝힌다. 다만 읽은 결과는 모델 제공자에게 전달되고 패키지는 npm에서 받는다. 사내·비공개 대상은 내용을 읽기 전에 사용자 확인을 받는다(스킬 본문에 명시) |
| 선례 | claude-video와 같은 직접 호출 전용. 상시 비용으로 기각한 graphify·agentmemory와 다르다 |

## 결정

1. 루트 스킬 `rea` 신설. 명시 호출 전용은 문구와 함께 기계 설정으로 건다 — Claude Code·Pi는 `disable-model-invocation: true`, Codex는 `agents/openai.yaml`의 `allow_implicit_invocation: false`.
2. **6.7.0 고정**. 2026-11-25 조회에서 `latest` 6.10.1의 Node 요구는 `^22.23.4 || ^24.22.1 || >=26.12.1`이라 이 컴퓨터(26.5.0)와 맞지 않았고, `npm pack rea-agents`가 고른 것은 6.7.0(`^22.19.0 || ^24.11.0 || >=26.0.0`)이었다. 중간의 6.8.0·6.9.0도 6.10.1과 같은 Node 범위를 요구한다(`npm view`). 바꾸려면 Node를 올린 뒤 새 버전을 다시 검토하고 스킬의 버전 표기를 모두 고친다.
3. 설치 스크립트를 끈다(`npm_config_ignore_scripts=true`). 선택 의존성 `frida`의 설치 단계를 피하려는 것이며 그 기능이 빠질 수 있다.
4. 상류 스킬 본문은 복사하지 않는다(MCP 도구 이름 중심이라 CLI 전용 사용과 맞지 않고, 사본은 낡는다).
5. MCP 도구까지 쓰려면 사용자가 별도로 등록해야 한다.

## 근거와 한계

- 확인: README·DISCLAIMER·상류 스킬·CLI/설치 문서 열람, 6.7.0 꾸러미를 실행 없이 풀어 동봉 스킬과 `package.json` 확인, Claude Code·Pi 공식 문서와 로컬 Codex 참조(`openai_yaml.md`)로 호출 설정 확인.
- **미검증**: REA CLI 실행(격리 시험 실행이 권한 분류기에 거부됨), 설치 스크립트를 끈 상태의 동작, 텔레메트리 부재(문자열 검색만), 각 CLI의 실제 자동 호출 차단.
- GitHub API가 보고한 별 수는 477,329개(생성 2026-04-14)로, 품질 근거로 쓰지 않았다.
