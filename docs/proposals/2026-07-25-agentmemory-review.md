# agentmemory 검토 — 기각 기록

- 날짜: 2026-07-25 / 상태: **기각** (사용자 확정 2026-07-25)
- 대상: https://github.com/rohitg00/agentmemory (MIT, npm `@agentmemory/agentmemory`)
- 관련: ADR 018(검색형 교훈 저장소 기각 — claude-mem), docs/proposals/2026-07-16-claude-mem-adoption.md, 루트 AGENTS.md §3·§8

## 대상 요약

AI 코딩 에이전트용 영속 메모리 시스템. 상시 로컬 서버(:3111, iii 엔진 고정 버전) + Claude Code 훅 12종이 **모든 도구 호출을 자동 캡처** → SHA-256 중복 제거 → 시크릿 필터 → LLM 압축(사실·개념·서사) → 임베딩(로컬/외부 6종) → BM25+벡터+지식그래프 하이브리드 검색(RRF 융합). 세션 시작 시 관련 기억 자동 주입(기본 2,000토큰). 4계층 메모리(작업/일화/의미/절차), Ebbinghaus 망각 곡선 기반 자동 삭제, 모순 감지, 버전·롤백(git 스냅샷), 팀 공유 메모리, MCP 도구 53종, MEMORY.md 양방향 브리지. 자체 벤치마크 주장: R@5 95.2%, 토큰 92% 절감(미검증 벤더 수치).

## 기각 근거

1. **ADR 018 정면 충돌**: "검색형 교훈 저장소(그래프/벡터 DB)는 만들지 않는다"가 이미 사용자 확정 결정이다(claude-mem 검토, 2026-07-16). 이 하네스의 축은 **축적이 아니라 승격** — 교훈은 auto-memory(파일)에 즉시 기록하고(§8), 반복 관찰이 확인된 것만 규칙·훅으로 승격, 큐레이션이 검색을 대체한다. agentmemory는 반대 방향(전량 자동 축적+검색)의 가장 강한 구현이라 부분 이식이 아니라 철학 교체가 된다.
2. **니치 기충족**: 전 세션 캡처·검색 → agentsview(설치·실측 운용 중, recall·finding-history), 교훈 영속 → auto-memory+MEMORY.md, 4계층 → _workspace(작업)/carryover·work-tracker(일화)/auto-memory(의미)/AGENTS.md·스킬(절차)의 **문서 구현**, 세션 시작 컨텍스트 → REGISTRY.md+AGENTS.md(생성물이 아닌 큐레이션), 시크릿 필터 → secret-gate+`<private>`+agentsview secrets. 남는 순증 기능이 없다.
3. **상시 비용 역행**: 세션당 2,000토큰 주입 + 매 도구 호출 훅 왕복 + LLM 압축 호출. ADR 030(영어 전환, 세션당 5~9k 절감)·40KB 예산 가드(R14)와 반대 방향. 절감 주장 수치는 벤더 자체 벤치마크라 근거로 쓸 수 없다.
4. **§3 우려 축**: 저장은 로컬이지만 외부 임베딩 프로바이더(Gemini/OpenAI 등) 사용 시 캡처된 세션 내용(회사 데이터 가능)이 외부 API로 전송된다 — 외부 DB 동기화 금지와 같은 축(로컬 임베딩 옵션은 존재하나 기본 안전이 아님).

## 마이크로 포팅 후보 검토 (전부 기수렴 판정)

| agentmemory 착안 | 판정 | 이유 |
|---|---|---|
| 모순 감지·supersession | 기수렴 | 메모리 지침 "틀린 기억 삭제·중복은 기존 파일 갱신" + `[[링크]]` 규약 |
| 주입 토큰 예산 | 기수렴 | MEMORY.md 한 줄 인덱스 규율(내용은 파일, 인덱스만 상시 로드) |
| PreCompact 재주입 | 기수렴 | CLI 내장 요약-연속 메커니즘 + carryover/wrapup |
| 저장 전 시크릿 필터 | 기수렴 | secret-gate 훅(전 저장소)·`<private>` 규약 |
| 자동 망각(decay·evict) | 충돌 | §8 ④ 수축은 **사용자 승인 후** 폐기 — 무단 자동 삭제는 원칙 위반 |
| 4계층 분류 프레이밍 | 기수렴 | 문서 구조로 동일 계층 이미 존재 — 규칙 추가는 순수 중복 |

## 재검토 조건

- ADR 018의 전제(큐레이션이 검색을 이긴다)가 실측으로 흔들릴 때 — 예: auto-memory 인덱스가 커져 회상 실패가 신호 ②로 2회 이상 잡히는 경우.
- 그 경우에도 1순위는 기설치 agentsview의 recall 계층 활용이며, agentmemory 신규 도입은 그다음 검토다.
