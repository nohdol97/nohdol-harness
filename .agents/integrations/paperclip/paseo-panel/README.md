# Paseo Paperclip 패널

Paseo의 사이드바와 워크스페이스 패널에서 같은 컴퓨터의 Paperclip을 조회합니다. React Native 화면과 Paseo RPC를 사용하므로 패널 조작에 LLM 호출이 필요하지 않습니다.

## 제공 기능

- 회사·프로젝트 선택, 이슈 목록·설명·최근 댓글 조회
- 회사 전체 에이전트 상태와 최근 실행 상태 조회
- 프로젝트를 지정한 **미배정 backlog 초안** 등록
- 확인 화면을 거친 에이전트 일시 정지. **진행 중인 실행도 취소됩니다.**

배정·실행·재개·댓글 작성·승인·삭제는 제공하지 않습니다. 새로고침은 수동이며, 화면은 조회 시각을 표시합니다. 워크스페이스 패널에서도 프로젝트를 직접 선택합니다. Paseo 워크스페이스 경로를 Paperclip 프로젝트로 자동 매핑하지 않습니다.

## 설치와 확인

대상은 Paseo `>=0.11.2 <0.12.0`, 같은 컴퓨터의 Paperclip `http://127.0.0.1:3100`, `local_trusted` 구성입니다. 설치된 Paperclip `2026.1012.0`의 API를 기준으로 작성했습니다. 인증 모드가 변경되면 우회하지 않고 연결 오류를 표시합니다.

```sh
cd .agents/integrations/paperclip/paseo-panel
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run typecheck
```

실행 의존성은 Paseo 플러그인 호스트가 제공합니다. `node_modules`는 개발 검증용이며 배포 자산이나 커밋에 넣지 않습니다. Paseo CLI의 `plugin install --help`에서 현재 설치 방법을 확인하고 이 디렉터리를 로컬 플러그인으로 설치합니다. 이후 사이드바의 **Paperclip**, 또는 워크스페이스의 **Paperclip** 패널을 엽니다. 기존 플러그인 활성화 설정과 원격 연결 설정은 별도로 보존해야 합니다.

폰은 기존 Paseo 연결을 사용합니다. 이 플러그인은 릴레이·VPN·인증을 설치하거나 변경하지 않습니다. 컴퓨터의 Paseo와 Paperclip이 실행 중이어야 합니다.

## 데이터 경계

클라이언트는 Paseo RPC만 호출합니다. 데몬은 `node:http`로 고정된 `127.0.0.1:3100/api`의 정해진 API에만 접근하며 환경의 HTTP 프록시를 사용하지 않습니다. 임의 주소·경로·메서드를 RPC 입력으로 받지 않고 리디렉션을 따르지 않습니다. 요청 제한은 8초, 응답 제한은 2 MiB입니다.

회사는 요청마다 확인하며, 프로젝트·이슈·에이전트의 회사 소속을 검증합니다. 초안 입력은 제목 1–200자, 설명 최대 20,000자, 프로젝트 UUID만 받습니다. 서버가 backlog·미배정·watchdog 없음·executionPolicy 없음으로 본문을 재구성합니다. 외부 객체 자동 감지 설정이 명시적으로 꺼져 있지 않으면 초안 등록을 거부합니다. 제목은 명시적으로 전달하므로 제목 생성 모델을 호출하지 않습니다.

agent config·환경 변수·실행 context·원시 로그를 반환하지 않습니다. 화면에 필요한 필드만 선택하며 일부 토큰 형식과 비밀 키 대입 패턴을 가립니다. **이 텍스트 마스킹은 모든 개인정보·비밀을 탐지하는 DLP가 아닙니다.** 사용자가 작성한 제목·설명·댓글은 일반 텍스트로 전달됩니다. 이 콘텐츠를 볼 권한이 있는 Paseo 연결만 사용하세요.

플러그인은 통계·외부 폰트·오류 보고·외부 요청을 추가하지 않습니다. Paseo 자체 연결의 릴레이·메타데이터 정책을 변경하지 않으며, Paperclip의 다른 기능이나 다른 사용자의 후속 배정까지 차단하지 않습니다. 로컬 프로세스를 신뢰하는 단일 사용자 배포를 전제로 합니다.

## 제한과 오류 처리

회사·프로젝트·에이전트와 이슈는 각 최대 100개, 실행은 최근 30개, 댓글은 최근 50개입니다. 설명은 20,000자, 댓글은 10,000자로 잘라 표시합니다. 이슈 목록의 개수는 조회 범위 내 개수이며 전체 집계를 보장하지 않습니다. 프로젝트 필터는 가져온 이슈 목록에 적용되고, 에이전트·실행 탭은 회사 전체를 보여 줍니다.

초안 등록·정지 도중 중복 클릭을 막고 자동 재시도하지 않습니다. 초안 등록 실패 시 입력을 보존합니다. 타임아웃은 서버의 처리 취소를 보장하지 않으므로 재등록 전에 목록을 확인하세요. 회사가 바뀌면 선택 이슈·프로젝트·초안 입력·확인 화면을 초기화합니다.

단위 테스트는 모의 HTTP만 사용하며 실제 업무나 에이전트를 수정하지 않습니다. 실제 UI·폰·Paseo 컴파일 결과는 상위 작업의 검증 기록에서 별도로 확인합니다.
