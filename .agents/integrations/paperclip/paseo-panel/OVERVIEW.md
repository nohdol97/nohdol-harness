# Paperclip

프로젝트와 이슈를 보고 작업을 요청하거나, 내 응답 필요 대기함에서 질문·확인에 응답합니다. 화면 조회는 모델을 호출하지 않습니다. 실행 요청·답변·승인·재개·재시도·추가 지시는 모델 호출로 이어질 수 있어 확인 후 제출합니다.

초안은 미배정 backlog로 저장합니다. 에이전트 재개는 다른 대기 업무에도 영향을 줄 수 있으며, 정지는 진행 중인 실행도 취소합니다. 지원하지 않는 관리·외부 도구·비밀 정보 요청은 읽기 전용으로 표시합니다.

기존 Paseo 연결과 localhost:3100의 Paperclip을 사용합니다. 지원 범위·중복 방지·불명확한 결과의 처리 방법은 README.md를 참고하세요.
